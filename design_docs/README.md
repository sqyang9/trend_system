# Design Docs

This directory holds design-layer documents that are still useful for understanding the system, but do not need to live in the repository root.

## Subfolders

- `multi_sleeve/`
  - architecture, chart-priority, dashboard specification, operating monitoring, and visualization design outputs
- `governance/`
  - governance boundary and re-engagement framework documents

## Purpose

These files are not rejected research.
They are support documents for architecture, operating visibility, and governance framing.

They were moved out of the root so the repository reads more cleanly:

- root = state + mainline + active engines
- `official_mainline/` = adopted baseline audit bundle
- `entry_and_warmup_audit/` = onboarding / startup studies
- `live_operating_layer/` + `dashboard/` + `historical_signal_atlas/` = operating layer
- `design_docs/` = support design documents
- `legacy_root_research/` = old process-history reports
