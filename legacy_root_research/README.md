# Legacy Root Research

This directory holds historical process-report files that used to live in the repository root but are no longer part of the active mainline read path.

It exists to make the root easier to navigate without deleting research history.

## Subfolders

- `v85_legacy/`
  - old long-only mother, gatekeeper, intrabar validation, and squeeze local-opt report outputs
- `addon_legacy/`
  - old AddOn grading, exposure-engine, collapse/repair, and compound-repair process reports
- `riskoff_legacy/`
  - old Risk-Off promotion, re-entry deep-dive, full-stack comparison, and superseded replacement-chain reports
- `sleeve_legacy/`
  - rejected sleeve / Sleeve #3 / post-damage participation branch reports and their companion outputs

## What Should Stay Outside This Folder

These should remain in their current locations:

- root-level state files
- `official_mainline/`
- `entry_and_warmup_audit/`
- `live_operating_layer/`
- `dashboard/`
- `historical_signal_atlas/`
- isolated reserve research directories such as:
  - `regime_detector_research/`
  - `gravity_penalty_research/`
  - `module_refinement_research/`
  - `s2_time_stop_research/`

## Practical Rule

If a file is only needed to understand a rejected or superseded branch from the old root-level process history, it belongs here rather than in the repository root.
