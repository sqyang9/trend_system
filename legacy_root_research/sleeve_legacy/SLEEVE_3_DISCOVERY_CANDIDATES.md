# Sleeve 3 Discovery Candidates

## Scope

- Locked formal portfolio: `Core BTC holding + ConstAddOn[1.00x] + RangeRotation`
- Approved governance cap: `3.0x`
- `Sleeve #1 = ConstAddOn[1.00x]`
- `Sleeve #2 = RangeRotation`
- This round is `Phase T1` only: candidate family generation

## Candidate Selection Rule

`Sleeve #3` must be materially different from both existing sleeves:

- not another `breakout / expansion` ecology cousin
- not another `range rotation / chop` ecology cousin

The target is a new return source that can help where the current two-sleeve stack is still structurally weak:

- recovery transitions
- post-trend reset / re-acceptance windows
- long underwater duration
- path smoothness after major dislocations

## Why These Are Non-Redundant

### `reset_base_reacceptance`

- Non-redundant because it explicitly requires a reset and rebuilt acceptance, not expansion.
- Non-redundant because it should trigger after the market has stopped behaving like a clean range and before it resumes classic breakout behavior.
- If valid, it can address the current stack's remaining weakness in recovery transitions and underwater duration.

### `failed_breakdown_acceptance`

- Non-redundant because it monetizes failed downside information, which neither existing sleeve targets directly.
- It should be active when the market's main message is “the selloff could not persist,” not “an upside breakout is underway” or “a range edge is rotating.”
- That gives it a distinct failure mode: it loses when downside acceptance resumes, not when breakouts decay or chop rotates poorly.

### `trend_drift_persistence`

- Non-redundant because it is a carry / persistence sleeve, not an expansion sleeve.
- It targets the long middle of a move where the breakout energy is already spent and the range edge is no longer the main source of edge.
- If valid, it could help smooth post-reset advances without needing dramatic trigger bars.

### `dislocation_repricing_rebuild`

- Non-redundant because it focuses on order restoration after disruption, not on breakout force or mean reversion inside a healthy range.
- It is the broadest “structural rebuild” family in this set and may capture sequences that are too damaged for `RangeRotation` and too late / messy for `ConstAddOn`.
- If valid, it could improve path smoothness after the most painful portfolio episodes.

## Which Candidates Are Most Likely To Help Current Path Burden

### Strongest candidates for remaining path help

1. `reset_base_reacceptance`
2. `failed_breakdown_acceptance`
3. `dislocation_repricing_rebuild`
4. `trend_drift_persistence`

Reason:

- The current two-sleeve stack already covers expansion and chop rotation.
- The most obvious missing ecology is “what happens after structure breaks, then gets rebuilt.”
- That makes reset / re-acceptance and failed-breakdown families more plausible than another trend or range cousin.
